# CloudeAlam Refund Policy

CloudeAlam provides refunds according to the conditions described in this policy.

## VPS Refund

New VPS customers can request a refund within 7 days of the initial purchase.

The 7-day refund period applies only to the first purchase of a VPS service.

Renewals are not eligible for the initial 7-day refund period.

## Managed Database Refund

Managed Database services are eligible for a refund within 3 days of the initial purchase.

Database usage charges may be deducted from the refundable amount.

## Object Storage

Object Storage usage is non-refundable.

Charges for stored data and network transfer are calculated based on actual usage.

## Refund Request

Customers can request a refund by opening a support ticket.

The request must include:

- Customer account
- Service name
- Reason for refund

Refund requests are normally reviewed within 3 business days.

## Non-Refundable Situations

A refund may be rejected when:

- The service has been used for prohibited activities.
- The account has violated the Acceptable Use Policy.
- The refund period has expired.
- The service has already received a previous promotional refund.

Approved refunds are returned to the original payment method when possible.
