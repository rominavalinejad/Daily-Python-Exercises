# CloudeAlam VPS

CloudeAlam VPS provides virtual private servers for running websites, APIs, development environments, databases, and other applications.

Each VPS includes dedicated virtual CPU resources, RAM, SSD storage, and a public IPv4 address.

## VPS Plans

### VPS Basic

- 2 vCPU
- 4 GB RAM
- 80 GB NVMe SSD
- 1 public IPv4 address
- 2 TB monthly network traffic
- 1 Gbps network connection
- Starting price: €8/month

VPS Basic is recommended for personal projects, small websites, development environments, and low-traffic applications.

### VPS Pro

- 4 vCPU
- 8 GB RAM
- 160 GB NVMe SSD
- 1 public IPv4 address
- 5 TB monthly network traffic
- 1 Gbps network connection
- Starting price: €16/month

VPS Pro is recommended for production APIs, medium-sized websites, backend services, and applications with higher resource requirements.

### VPS Business

- 8 vCPU
- 16 GB RAM
- 320 GB NVMe SSD
- 1 public IPv4 address
- 10 TB monthly network traffic
- 2 Gbps network connection
- Starting price: €32/month

VPS Business is recommended for production applications, high-traffic websites, and larger backend systems.

## Operating Systems

Supported operating systems include:

- Ubuntu 24.04 LTS
- Debian 12
- AlmaLinux 9
- Rocky Linux 9

Customers can select the operating system during server creation.

## Server Locations

VPS instances are currently available in:

- Frankfurt Zone 1
- Frankfurt Zone 2
- Frankfurt Zone 3

## Backups

Automated backups are available as an optional feature.

VPS backups are created once every 6 hours when automated backup is enabled.

Customers can keep up to 7 daily backup points.

Backup storage is billed separately.

## Scaling

Customers can upgrade their VPS resources from the CloudeAlam dashboard.

CPU and RAM upgrades may require a short restart.

Storage upgrades are available without changing the VPS IP address.

Downgrading CPU or RAM is not currently supported directly from the dashboard.

## Network

Every VPS includes a public IPv4 address.

Private networking between VPS instances in the same availability zone is supported.

Private network traffic between VPS instances in the same zone is free.

## Important Limitations

VPS instances are not designed for:

- Cryptocurrency mining
- Spam distribution
- Network attacks
- Malware hosting
- Illegal content

Resources may be suspended if they are used for activities that violate CloudeAlam's Acceptable Use Policy.
